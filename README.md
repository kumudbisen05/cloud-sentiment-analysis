# ☁️ GCP Sentiment Analysis App

A simple web app that uses **Google Cloud Natural Language API** to analyze the sentiment of text entered by the user.  
Built using **Python** and **Streamlit**, and can be deployed easily on **Google Cloud Run** or **App Engine**.

---

## 🔧 Technologies Used
- Google Cloud Platform (GCP)
- Cloud Natural Language API
- Python
- Streamlit

---

## 🚀 How It Works
1. User enters text in the app.
2. The app sends the text to GCP's **Natural Language API**.
3. The API returns the **sentiment score** (positive/negative/neutral).
4. The result is displayed beautifully using Streamlit.

---

## 🧠 Why I Built This
This project demonstrates how to integrate **machine learning APIs** from GCP into a simple web app.  
It reflects the power of cloud-based NLP and real-time text analysis.

---

## 🧩 Deployment Ideas
- Deploy using **Google Cloud Run**.
- Use a **Service Account key (JSON)** for authentication.
- Or run locally with `streamlit run app.py`.
