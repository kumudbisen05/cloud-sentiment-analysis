# 🌐 Cloud Sentiment Analysis

AI-powered platform to analyze text sentiment (Positive, Negative, Neutral) using Python and Flask.

> ⚠️ Note: The project is fully functional locally but has **not yet been deployed on GCP** due to account/payment limitations.

---

## Features
- Analyze single text input
- Analyze CSV files (future)
- Display sentiment results in a clean web interface

---

## Technologies Used
- Python, Flask
- TextBlob
- HTML, CSS, JavaScript
- Optional: pandas for CSV handling

## Why I Made This Project
I created this project to **learn and demonstrate how AI/ML can be applied to real-world problems** like analyzing text sentiment. It helps understand how to process text data, use sentiment analysis libraries like TextBlob, and integrate Python with web applications. Additionally, it serves as a practical tool to **quickly determine the sentiment of text**, which can be useful for social media monitoring, customer feedback, or market research.  

This project also allowed me to **practice cloud deployment concepts**, even though it is currently running locally, preparing me for future GCP/AWS deployment.
